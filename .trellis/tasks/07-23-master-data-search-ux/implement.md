## 风险与回滚点

- 相关性候选排序可能增加云函数读取量；候选上限和超量提示必须可配置，超时可暂时退回原业务排序。
- 主数据页面结构和测试料型号入口是用户可见变更；保留旧路由和导入工作流作为回滚路径。
- 首页搜索触发变更可能影响已有“输入即跳转”的测试断言；更新测试为显式导航契约，不删除库存结果页能力。
